# Customer Churn & Revenue Intelligence System

## Project Overview

An interactive data analytics and machine learning project that explores customer churn patterns, revenue trends, and customer retention.

## Features

* Customer churn analysis
* Revenue analysis
* Interactive Streamlit dashboard
* Customer segmentation by contract and payment method
* Random Forest classification model
* Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Matplotlib and Seaborn
* Plotly
* Streamlit

## Dataset

This project uses a **synthetic dataset of 1,000 customers** generated for educational purposes. The results do not represent actual customer behavior.

## How to Run

1. Clone or download this repository.

2. Install the required libraries:

   `pip install pandas numpy scikit-learn matplotlib seaborn plotly streamlit`

3. Run the dashboard:

   `streamlit run app.py`

4. Open `src/train_model.py` to train and evaluate the churn prediction model:

   `python src/train_model.py`

## Objective

To demonstrate an end-to-end data analytics workflow, including data generation, exploratory data analysis, machine learning, and interactive visualization.
